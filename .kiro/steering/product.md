# Kiro project steering / Syllogism of the Damned

- Competition: Kiroween 2026; Costume Contest. Official competition rules override any interpretation in this document.
- User has approved v0.3 as the scope: one named form, exactly one intelligible puzzle, 32 decorative fragments and a chamber that responds to moving NOT from one sentence to another.
- A beautiful puzzle is not automatically intuitive: the next action must be clear, while its consequence is surprising.
- Avoid 3-click scavenger hunts, random puzzles, gratuitous LLM integrations, UI clutter, surprise fullscreen, remote dependencies and unapproved costs.
- Use plain en-GB UI language, visible keyboard focus, reduced motion, feedback next to interactions, and no scroll on desktop demo viewport.
- `src/engine.mjs` owns rules; animations do not grant authority. Names must never become HTML.
- Preserve version branches and working backups; never edit `main` before explicit approval. Publish only reproducible results.
- `.kiro` specs and steering are not evidence of genuine Kiro IDE usage. This must be documented honestly through actual Kiro activity.
